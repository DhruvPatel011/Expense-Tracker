# Tracklix Frontend

A modern and responsive Personal Finance Tracker frontend built with HTML, CSS, JavaScript, and Chart.js.

Tracklix helps users manage income, expenses, savings, and monthly budgets through an intuitive dashboard, interactive analytics, and a seamless user experience.

---

## Live Demo

https://expense-tracker-gamma-ruddy.vercel.app/

---

## Features

### Authentication Interface

* User Registration
* Secure Login System
* OTP-Based Password Reset Flow
* Form Validation
* Password Strength Indicator

### Dashboard

* Financial Overview Cards
* Income & Expense Summary
* Current Balance Tracking
* Savings Rate Calculation
* Recent Activity Section

### Transaction Management

* Add, Edit, and Delete Transactions
* Category-Based Organization
* Search and Filter Functionality
* Transaction History

### Analytics & Reports

* Expense Distribution Charts
* Income vs Expense Analysis
* Savings Insights
* Interactive Data Visualization

### Budget Management

* Monthly Budget Tracking
* Spending Progress Indicators
* Budget Status Monitoring

### User Experience

* Responsive Design
* Dark/Light Theme Support
* Toast Notifications
* Smooth Animations
* Mobile-Friendly Layout

### Export Functionality

* CSV Export
* PDF Report Generation
